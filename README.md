# FlowCut

**FlowCut Studio** is a browser-based video template editor for creating personalized, template-driven marketing videos.

It provides a simple editing workflow where users can choose a template, provide dynamic content, upload media, customize properties, add captions and music, and build a final video through a timeline-based interface.

## ✨ What is FlowCut?

Creating personalized marketing videos usually requires a lot of repetitive editing. FlowCut explores a more scalable approach: **build the video once as a reusable template, then customize the content for each recipient or use case.**

The editor is designed around reusable video templates with configurable properties such as recipient names, product information, presenter videos, branding, captions, and media assets.

## Personalization

FlowCut is designed around the idea of separating **video structure from video content**.

For example, a template can define a reusable structure while individual values can be customized:

```text
Recipient Name
Phone / Product Name
Presenter Video
Product Image
Brand Logo
Captions
Music
```

This makes the same creative format reusable across multiple personalized videos.
